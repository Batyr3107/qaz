## 🚀 Быстрый старт

### Вариант 1: Прямое открытие
```bash
# Просто откройте index.html в браузере

```

### Вариант 2: Локальный сервер (рекомендуется)
```bash
# Python 3

# Node.js
npx serve

# PHP
php -S localhost:8000
```

Затем откройте: `http://localhost:8000`
